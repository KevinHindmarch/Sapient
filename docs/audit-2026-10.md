# Platform audit — October 2026 (after v0.5.0)

Six parallel reviews (research, portfolio bookkeeping, automated trading, TWS
execution, UI wiring, desktop/ops). Findings were reproduced against a temp
database with mocked Yahoo data and the fake TWS from the test suites unless
marked *(read)*. All 210 existing tests pass; nothing below is caught by them.

Severity: **S1** can lose money, trade the wrong account or disable safety ·
**S2** wrong numbers or a feature that silently doesn't work · **S3** gap/UX.

## 7. UI wiring and UX

All `lib/api.ts` calls hit real routes. Gaps: no Scan button although Inbox/Settings tell the user to press one (`/api/ai/scan` unused); no manual-trade form (`/trade` unused); queued simulation intents invisible; pages hang with no timeout when Yahoo is slow; Yahoo failures surface as "Found 0 signals", "Insufficient data", raw curl text; raw error codes (`account_halted`); Brokerage card "Checking…" forever when TWS not set up; sidebar not sticky (Settings below the fold at 768 px); onboarding doesn't lead to a first portfolio; AI Inbox tabs overflow at 390 px; React key-spread console error in `AutonomyChecklist.tsx`; duplicate toasts on a missing portfolio.

## What was checked and works

ASX hours/DST/early closes and 2026–27 holidays; tick rounding; order-id monotonicity and separate live range; no `reqGlobalCancel`; never resend on unknown; partial fills and corrections; TWS restart reconnect; live real-time-only pricing; paper/live separation; cash check before buys; single-instance lock; UTC timestamps; crash mid-send ⇒ UNKNOWN; token/CSP/loopback; every route renders; light/dark; empty states.
